// 01 · problem

异构 FM 直接替换，
Brain 会读不懂。

场景

用 Grounding DINO / LLMDet 替换 RoboAgent 的 object grounding。检测可能成功，但标签词表 / 格式 / 语义 ≠ Brain 契约。

Naive 后果

SR 34%（Native 78%）。大量失败是 lpm_error：检测到了，下游动作却错——典型合同失配。

还缺两件事

① 多技能需要统一、可类型检查、可审计的通道
② Brain 要消费 found / confidence / uncertainty，不只是 class 名

对照代码

agents/naive_detector.py
原始检测标签直通 Brain

agents/agent.py
Think→Query → skills → LPM

问题很具体：把 Grounding DINO 或 LLMDet 直接塞进 object grounding，会发生什么？

检测器可能已经“看到”物体了，但输出的词表、格式、语义不等于 Brain 期待的契约。比如 Brain 要 CellPhone，你给它 phone——下游 LPM 就会做错动作。

Naive 配置 SR 34%，相对 Native 78% 是灾难性退化。失败 taxonomy 里大量是 lpm_error：检测成功、动作失败——所以根因是合同失配，不是“检不到”。

此外还有两件事：多技能不能各说各的字段；Brain 需要决策信号 found / confidence / uncertainty。

对照代码：失败侧看 naive_detector.py；Brain 调度看 agent.py。下一页看主结果怎么被 Adapter 拉回来。

// 02 · evidence

怎么证明不是运气？

Exact McNemar

Align vs Naive，同 episode 配对。
b=23（Naive 败 Align 胜）
c=0（反向）
p ≈ 2.4e-7 < 0.001
0 regression · 23 recovered

DA-FT

35 例 × 5 信号态 = 175 probes。
只改 found/confidence/uncertainty。
决策准确率 172/175 = 98%
signal-sensitive 34/35
raw-FT 仅 40%，且 0/35 sensitive

Ablation

canonical 48%
canonical+signals 61%
flat-USR 58%
shuffled-USR 28%
打乱信号就崩 → 学的是 signal→decision

三块证据。

第一，Exact McNemar：同一 episode 上比 Align 和 Naive。Naive 失败 Align 成功有 23 集，反过来 0 集，p 约 2.4e-7。所以不是偶然波动，而且没有 regression。

第二，DA-FT：固定 RGB/目标/历史/物体类，只改 USR 决策信号，5 种状态。决策准确率 98%，34/35 例会对信号敏感；raw-FT 还是 40%，而且对信号不敏感。

第三，消融：加 signals 到 61%，flat-USR 58% 差不多；把 signals 打乱 掉到 28%。这说明模型学的是映射，不是记住 USR 字符串长什么样。

第一层，Foundation Models。OG / SD / EG 都是可替换后端。检测走 registry，SD 可切 Florence-2，EG 可切独立 LoRA——FullIndep 配置就用到 eg-LoRA。

第五层是冻结的预训练 Brain。

Scheduler 用 Think→Query：思考后发起技能查询，结果进 buffer，再继续。LPM 是动作解码，对应 manipulation_planner，最终策略是 execute、guard（观望）、reobserve（再看）。

Decision-aware training 的故事：让 Brain 会用 USR 里的 found/confidence。本仓库是 frozen 实验代码，训练全量在实验机 frozen_final_closure_*；运行时可用环境变量挂 DA-FT LoRA。细节见研究文档。

// 05 · ablation

USR 的价值在决策信号

控制变量

同一数据池 / split / 样本数 / epochs(4) / batch(6) / lr(2e-4) / 优化步数 / 初始化 / 评测集。
唯一差别：输入表征。

读数

canonical 48% → +signals 61%
flat-USR 58% ≈ +signals
shuffled-USR 28% 崩盘

反事实 5 态：只有 +signals / flat-USR 达到 5/5

所以：不要把收益归因成“换成 USR 字符串格式”；归因成 显式 decision signals。

这页专门防误解。

消融里一切训练超参锁死，只改输入。加上 found/confidence 之后从 48 到 61；flat-USR 58，差不多；把信号随机打乱掉到 28。

结论很干净：模型学的是 signal→decision 映射。USR 序列化本身不是主因；USR 的工程价值是把信号结构化、可审计、可经 SkillChannel 安全投喂。

Align+USR 主表是 78% 也可以这么解释：接口统一了，但 SR 主提升已经在 Adapter。

// 05 · findings

三条结论

01
Adapter 是主贡献

naive 34% → aligned 80%（+46pp）。主导失败模式：下游合同失配（检测成功、动作错误）。

02
USR 价值在决策信号

canonical+signals 61% ≈ flat-USR 58%；shuffled 28% 证明学的是信号映射，不是序列化。

03
DA-FT 让 Brain 会用信号

决策准确率 98%（172/175）vs raw-FT 40%；signal-sensitive 34/35。

收束就这三条，建议原样说。

一，Adapter 主贡献，34 到 80，失败主因合同失配。二，USR 的行为增益来自显式决策信号。三，Decision-aware training 让 Brain 真的消费这些信号。

一句话总结：技能可以换，但必须先对齐契约，再经 USR + SkillChannel 把决策信号安全交给 Brain。
